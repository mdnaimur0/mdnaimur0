## 👨‍💻 About Me

I am a backend-focused **full-stack developer** based in Bangladesh, building production-ready **web and mobile** applications since 2020. I design and develop scalable backend systems using **Python** (FastAPI, Flask) and **Node.js** (Express.js), with strong emphasis on clean *architecture, performance, and maintainability*.

I build modern web applications using **React and Next.js**, and develop cross-platform mobile applications with **Flutter** as well as native **Android** applications.
